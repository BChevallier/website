# website

The source of [bastienchevallier.eu](https://bastienchevallier.eu): a bit about me, my projects, and some talks I've given.

Plain HTML, CSS and JavaScript, served straight from `site/` by GitHub Pages. There's no build step. The talks are reveal.js decks in `site/presentations/`.

The layout is based on [Spectral](https://html5up.net/spectral) by HTML5 UP (CC BY 3.0). Everything else is MIT.
